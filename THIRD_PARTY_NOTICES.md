# Third-party notices

Mythic+ affixes, weekly Mythic+ runs, scores, raid progression and current
raid dates come from the public [Raider.io API](https://raider.io/api). No API
key is used. Raider.io data is rendered as plain text.

Optional faction icons are derived at runtime from the Horde and Alliance emblems
on [warcraft.wiki.gg](https://warcraft.wiki.gg) (`File:HordeLogo.png`,
`File:Alliance Logo.png`). They are downloaded to the user's machine and never
distributed with this plugin. The emblems are trademarks and copyrighted artwork
of Blizzard Entertainment, Inc.

`FactionIcon.qml` is adapted from ninepointlabs' Fastmail Omarchy plugin.

Optional raid lockouts come from the Blizzard Battle.net World of Warcraft
Profile API, using client credentials the user creates at
[develop.battle.net](https://develop.battle.net). World of Warcraft and
Battle.net are trademarks of Blizzard Entertainment, Inc. This plugin is not
affiliated with or endorsed by Blizzard or Raider.io.

`bin/bounded-run` and the store code in `bin/wow-reset-ops` come from
ninepointlabs' Upcoming Omarchy plugin.
